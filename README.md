# VYBE Music

VYBE is a black-heavy burgundy glass music discovery app.

- Music search is proxied through a backend route.
- The YouTube API key is **not stored in this repository**.
- Production uses a backend secret named `YOUTUBE_API_KEY`.
- Playback uses the official YouTube embedded player.

Live app: https://vybe-music-7ryv0t.v2.appdeploy.ai/
